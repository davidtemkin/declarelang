# a grid holds its own header, a range takes two thumbs, and a combobox takes a new name

A [`DataGrid`](declare-docs:DataGrid)'s header row is now the top of the grid's own box, pinned there while the
rows scroll up under it — so a grid placed by a layout covers nothing beside it. What the
Ledger builds made by hand is now in the library: a [`RangeSlider`](declare-docs:RangeSlider) for a range on one
track, a [`Combobox`](declare-docs:Combobox) that offers what was typed as a new item ([`creates`](declare-docs:Combobox.creates)), grid cells
that commit once on Enter and go to a service through [`editInput`](declare-docs:DataGrid.method.editInput), and a
[`Stepper`](declare-docs:Stepper) you can type a number into.

```declare-fragment
amount: RangeSlider [ min = 0, max = 500, step = 5, accessibilityLabel = "Amount",
    low = { app.lo }, high = { app.hi },
    commit(low: number, high: number) { app.lo = low; app.hi = high } ]
```

Hold ⌘ (Ctrl elsewhere) a moment, and a program that labels its key bindings shows them: the
[`ShortcutsPanel`](declare-docs:ShortcutsPanel) comes with the library, the keys spelled as the person's keyboard spells
them.

## Breaking changes

### a `DataGrid`'s header stands above its box → it is the top of the box
The header row used to paint above the grid, in the space before it, so a grid needed room
left above it — and in a layout it covered whatever came before. It is now inside the box:
the grid's height is its header and its rows.

```declare-fragment
grid: DataGrid [ x = 20, y = 50, width = 400, height = 130, items = { app.rows },
    columns = { [ { id: "title", title: "Title", width: 240 } ] } ]
```

```declare-fragment
grid: DataGrid [ x = 20, y = 20, width = 400, height = 160, items = { app.rows },
    columns = { [ { id: "title", title: "Title", width: 240 } ] } ]
```

Docs: [`DataGrid.headerH`](declare-docs:DataGrid.headerH)

Watch for: a grid placed with room left above it for its header now shows a gap there, and
its rows start lower; move it up by the header's height (`gridHeaderHeight`, 30) and make it
that much taller. A wrapper whose top `padding` made room for the header no longer needs it.

## Smaller changes

- **A press into a `Combobox`'s field opens its list**, as a select does — on a phone, the
  choices show before a word is typed. Tab arriving stays quiet.
- **A boot failure inside the library names where in the program it happened** — `while
  working out Dataset.contents at app.when._pop.cal._model` — so the use site whose values
  to check is in the message, not only the library's lines.
- **A press of the pointer ends a ⌘ hold**: a ⌘-click or a ⌘-drag never shows the
  shortcuts panel.
- `Keyboard.shortcutsInForce()` records carry `keyLabel`, the key as the platform spells it.
