## What the language evidence says

- **The onboarding works cold at Opus tier.** Every rep found the docs, wrote the program, ran the repo's own checker, and iterated to green unaided. Median 29–41 turns for the three simple tasks.
- **Shelf's spread is the signal.** All three reps built working drag-and-drop, but by different routes: r1 derived per-shelf collections in data (the reference's idiom), r2/r3 replicated the whole collection and filtered with `visible = { :shelf == side }`. Both shapes are brief-conformant; the split shows **filtered replication has no single taught form** — the corpus's derived-dataset idiom competed with the visible-filter idiom 1:2. If one is house style, the docs don't say so strongly enough to converge three runs of the same model.
- **The corridor semantics did not trip fresh programs.** Both r2 and r3 annotated the ghost's *label* with `pointerEvents = "none"` (r3 even wrote the comment "so it is never the answer to a hit test"). The regenerated reference prose taught the new rule successfully. The Aug-17 regression's victims are *existing* programs and the front-door docs, not new Opus-written code.

## Harness defect found (and fixed): the assert judged the tree, not the screen

`shelf`'s block-counting walk pushed every structural node and never checked `shown`. r2/r3's hidden filtered replicas (correct: `visible = false`, skipped by layout, absent from the screen) were counted as blocks → "left shelf should seed 3, found 5." Probed r3 live: exactly 3 shown left / 2 right at correct proportional widths — a correct program failed by the acceptance. Fixed (`assert.mjs` now skips `shown === false` subtrees, with a comment recording this round), reference re-verified green, both cells rescored against their persisted programs — full ladder including the drag assertions. Metrics lines carry a `rescored` annotation; solver artifacts untouched.

Same defect class as the width≥30 filter the assert's own header narrates from 2026-08-08. Standing rule worth adopting: **an assert walk starts from what is shown.**
